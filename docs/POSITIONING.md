# Valkiria PULSE positioning

## Core proposition

**Cada red. Su propio pulso.**

Valkiria PULSE is not positioned as another calendar with an AI text box. Its product architecture is built around one shared Brand Brain plus independent platform agents.

## Product difference

1. **Shared truth, isolated execution**
   - Brand identity is shared.
   - Instagram, TikTok and LinkedIn keep separate editorial prompts, memory and performance signals.

2. **Platform agents, not one generic assistant**
   - Instagram works visual-first.
   - TikTok works hook/video-first.
   - LinkedIn works professional-context-first.

3. **Orchestration**
   - A common campaign objective can be routed into three native executions instead of copying one post across channels.

4. **Feedback remains platform-specific**
   - Performance signals improve future editorial decisions only for the matching network.

5. **Operations disappear from the user's daily workflow**
   - Social authorization happens once per account.
   - Credentials stay encrypted server-side.
   - Token lifecycle, scheduling, providers and publication state are handled by PULSE.

## UX principle

The user should work with:
- brand;
- objective;
- content;
- approval;
- calendar.

The user should not need to understand:
- OAuth scopes;
- access tokens;
- refresh tokens;
- provider endpoints;
- API versions;
- scheduler internals.

## Competitive framing

Planning, scheduling, AI writing and analytics are table stakes in modern social media management.

PULSE should therefore lead with its architectural difference:

> One brand brain. One specialized agent per network. No mixed editorial memory.

Avoid claims that competitors do not adapt content by channel. The differentiation is the explicit separation of agent context, memory, workflow and performance feedback per platform.
